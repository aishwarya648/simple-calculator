# Simple Calculator (Python)

A simple calculator built in Python that performs basic arithmetic operations.
Developed as **Task 1** of the Python Programming Internship at **Syntecxhub**.

## Features
- Addition, subtraction, multiplication, and division
- User input through the command line
- Handles invalid input and division by zero

## Tech Stack
- Python 3

## How to Run
1.Open calculator.py in VS Code
2.Click the ▶ Run button at the top right
3.The output appears in the terminal at the bottom, type your inputs there
